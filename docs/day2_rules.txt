ITEMS (items.csv)
Required Columns
sku
name
cost_price
selling_price
current_stock

Default Values
category → NULL (optional)
safety_stock → 0
min_order_qty → 1
Reject File If
sku missing
name missing
cost_price < 0
selling_price < 0
duplicate sku inside file
current_stock not a number
any required column missing

SUPPLIERS (suppliers.csv)
Required Columns
name

Default Values
contact_email → NULL
lead_time_days → 7
reliability_score → 1.0
Reject File If
name missing
reliability_score < 0 or > 1
lead_time_days < 0
duplicate supplier name inside file

DEMAND ORDERS (demand_orders.csv)
Required Columns

sku
customer_name
quantity
due_date
priority

Default Values
status → OPEN

sku does not exist in items table

due_date invalid format
priority not in (LOW, MEDIUM, HIGH)
required column missing
